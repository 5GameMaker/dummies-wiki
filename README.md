"For Dummies!" is a collection of writeups for me to use personally.

For building the website, do `$ cargo run`.
Resulting webroot will be located at `target/web`.

Use whatever web server you like, i.e. `python -m http.server`.

Webroot can be specified as an extra argument `$ cargo run [path]`.

## Contributing

If you're a developer of a project, I'd highly recommend not to contribute to this wiki yourself.
Have someone outside of it learn it and write a page, as it's entirely possible that what you will
post will simply be too big to be comprehended quickly. Dummies Wiki is not meant to be an
all-comprehensive resource, just a small one. Submitting corrections is still good though.

P.s. this is just a suggesion, just keep it in mind.

What is not a suggestions though - use of GenAI here is strictly banned and anyone found submitting
anything generated with GenAI will be banned from the repository. GenAI output cannot be referenced
either. If you're using it for learning, *ask it for a source and actually read it yourself*.
